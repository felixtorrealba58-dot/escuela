# Sistema de Personal y Ficha Técnica - C.E. Zazarabicoa (1946)

Sistema web ligero, moderno y autónomo para el registro, consulta y generación de fichas técnicas oficiales del personal de la institución educativa en **Hoja Tamaño Carta (Letter / 8.5" x 11")**, exportable directamente a PDF o imprimible con máxima nitidez.

## 🚀 Cómo Usar el Sistema

1. Abra el archivo `index.html` con cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Opera, etc.).
2. **Para registrar a un funcionario**:
   - Complete los datos personales: Nombres, Apellidos, Cédula (V/E), Teléfono, Correo, Dirección y Fecha de Nacimiento (Día, Mes, Año).
   - Ingrese los títulos académicos: Pregrado, Postgrado o marque la casilla de Bachiller.
   - Seleccione la Categoría:
     - **1. DOCENTE**: Código de cargo/RAC, Nivel (1 al 5), Cargo (Directivo, Coordinador, Docente de aula), Área de trabajo y Condición (Activo o De Reposo).
     - **2. ADMINISTRATIVO**: Nivel (campo libre para rellenar), Área de trabajo especificada y Condición.
     - **3. OBREROS**: Nivel (campo libre para rellenar), Área de trabajo especificada y Condición.
   - Coloque el **Año o Fecha de Ingreso** y el sistema **calculará automáticamente en tiempo real los Años de Servicio**.
3. **Para Generar e Imprimir la Ficha Técnica**:
   - Haga clic en **"🖨️ Guardar y Generar Ficha Carta / PDF"** o búsquelo en el directorio y pulse **"🖨️ Ficha"**.
   - Se abrirá la vista previa en formato de hoja Carta con el logotipo oficial del plantel (Zazarabicoa 1946).
   - Presione el botón azul **"🖨️ Imprimir / Guardar en PDF"**.
   - En el cuadro de diálogo del navegador, seleccione como destino: **"Guardar como PDF"** o su impresora física conectada. El tamaño está preconfigurado en **Carta (Letter)** con márgenes calibrados para quedar en una sola hoja impecable.
4. **Respaldo y Exportación**:
   - En la pestaña **Directorio de Personal** puede descargar un archivo Excel (`.csv`) con toda la nómina o un archivo de respaldo (`.json`) para resguardar la información o transferirla a otra computadora.
